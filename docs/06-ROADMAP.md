# Roadmap Execution

## Phase 1 (MVP Togo)
- Auth + profil eleve (classe/serie/etablissement).
- Catalogue cours PDF + quiz + annales de base.
- Activation ticket par code.
- Offline PDF + quiz.
- Tracking analytics essentiel.

## Phase 2 (Croissance locale)
- Concours parametres + classement.
- Cours live Zoom + notifications.
- Enquetes hebdomadaires et dashboard besoins.
- Partenariats lycees et regles de debloquage.

## Phase 3 (Monetisation et ecosysteme)
- Site externe complet (tickets + billetterie event + promotions).
- Marketplace scolaire.
- Parrainage avec anti-fraude.
- Regles marketing avancees (gratuit total/partiel/campagnes).

## Phase 4 (Scale Afrique)
- Parametrage nouveaux pays sans changer schema.
- Multiples systemes de classes/series/examens.
- Orientation universitaire IA a grande echelle.
