# Concours, Evenements, Parrainage

## Concours
- Parametrables par classe/serie et periode.
- Conditions d'entree: gratuit, ticket `HALF`, ticket `FULL`, ou partenariat.
- Cadre definissable: nombre de tours, bareme, bonus vitesse, jury.
- Classement final avec recompenses (ticket, cadeaux, badge, bourse).

## Evenements
- Types: cours special, formation, concert, session orientation.
- Billetterie geree sur site externe; pass synchronise dans l'app.
- Tarification configurable selon profil ticket.
- Gestion capacite, file d'attente, QR/pass verification.

## Parrainage
- Chaque utilisateur a un code invite.
- Recompenses progressives:
  - Filleul actif 7 jours: XP bonus.
  - Filleul active ticket: jours bonus ticket ou coupon site.
- Anti-fraude: limite par appareil, verification telephone, scoring risque.

## Gouvernance
- Toute action concours/evenement emet des evenements analytics.
- Tableau de bord admin: inscriptions, conversion ticket, retention.
