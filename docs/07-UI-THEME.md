# UI Theme Guide

## Palette
- Primaire: `#2F80ED` (bleu clair).
- Secondaire: `#56CCF2` (bleu support).
- Accent: `#F2994A` (orange).
- Surface: `#F5F9FF`.
- Texte principal: `#1F2937`.

## Style
- Interfaces basees sur cartes et blocs contextuels.
- Feed scrollable personalise selon classe/serie.
- Widget intelligent en haut de l'accueil:
  - rappel revision,
  - concours en cours,
  - evenements proches,
  - promotions tickets/campagnes.

## UX principes
- Navigation rapide en 3 niveaux max.
- Etat acces visible partout (FULL, HALF, Gratuit, Partenaire).
- Date d'expiration ticket affichee de maniere persistante.
- Mode offline tres lisible (badge + statut sync).
