# Analytics, ML et Orientation

## Evenements minimaux
- `lesson_opened`, `pdf_downloaded`, `quiz_started`, `quiz_submitted`.
- `ticket_activated`, `access_denied`, `campaign_applied`.
- `contest_joined`, `event_registered`, `live_class_attended`.
- `survey_answered`, `referral_sent`, `referral_converted`.

## Dimensions requises
- pays, classe, serie, matiere, chapitre.
- type ticket, statut partenariat, campagne active.
- plateforme (web/android/ios), version app, mode offline/online.

## Usage data
- Tableau engagement quotidien/hebdomadaire.
- Detection de friction par chapitre difficile.
- Segmentation pour campagnes ciblage.

## Orientation universite (Gemini)
- QCM + questions ouvertes.
- Profil produit: interets, forces, contraintes, recommandations.
- Trace explicable: score par domaine, recommandations justifiees.
- Stockage securise et consentement explicite.

## Qualite et conformite
- Retention policy par type de donnees.
- Pseudonymisation pour analyses ML.
- Suppression complete des donnees sur demande utilisateur.
